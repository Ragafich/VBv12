# ЗМЕЙКОГОР: Путь героя

Консольная текстовая RPG на чистом Python. Игрок создаёт героя, сражается с монстрами, покупает снаряжение в магазине и повышает уровень, продвигаясь по карте.

## Возможности

- Создание героя с именем
- Пошаговые бои с монстрами (удар, зелье, побег)
- Система золота, атаки и защиты
- Магазин с предметами: оружие, броня, зелья
- Инвентарь героя
- Рост уровня монстров по мере прохождения
- Карта локаций
- Встроенная справка по командам

## Требования

- Python 3.8+
- Дополнительные библиотеки не нужны (используется только стандартная библиотека)

## Запуск

```bash
python game.py
```

## Команды

| Команда   | Действие                        |
|-----------|---------------------------------|
| `стат`    | Показать героя и инвентарь      |
| `карта`   | Показать доступные локации      |
| `магазин` | Открыть магазин                 |
| `идти`    | Отправиться в бой               |
| `помощь`  | Показать список команд          |
| `выход`   | Выйти из игры                   |

## Ход игры

1. Введите имя героя.
2. Загляните в магазин и купите снаряжение на стартовое золото.
3. Командой `идти` отправляйтесь в бой.
4. В бою выбирайте действие цифрой: `1` — ударить, `2` — выпить зелье, `3` — попытаться сбежать.
5. За победу над монстром начисляется золото, а уровень героя растёт.

## Структура

```
vb_oc_bylat/
└── game.py        # вся игра: модели, бой, магазин, интерфейс
```

### Основные части `game.py`

- `Item`, `SHOP` — предметы и ассортимент магазина
- `Hero` — герой: здоровье, золото, характеристики, инвентарь
- `Monster`, `MONSTERS`, `make_monster` — монстры и их генерация
- `battle` — логика боя
- `shop` — логика магазина
- `show_map`, `show_help` — интерфейс
- `main` — главный цикл игры
